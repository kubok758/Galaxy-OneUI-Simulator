# Samsung Galaxy One UI 8.5 Simulator

Интерактивный веб-симулятор Samsung Galaxy S25 Ultra, выполненный на React 18, TypeScript, Vite, Tailwind CSS, Framer Motion и Zustand. Проект работает полностью в браузере, не требует сервера приложений и сохраняет пользовательское состояние в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес, обычно `http://localhost:5173`.

Сборка для production:

```bash
npm run build
npm run preview
```

## Управление

- PIN по умолчанию: `2580`.
- Свайп вверх по экрану блокировки открывает PIN-клавиатуру.
- Свайп влево на экране блокировки запускает камеру.
- Свайп вверх на рабочем столе открывает меню приложений.
- Свайп вниз открывает панель уведомлений; повторный свайп разворачивает Quick Settings.
- Долгое нажатие на иконку открывает контекстное меню.
- Иконки можно перетаскивать между двумя домашними экранами.
- Клавиша `Escape` работает как системная кнопка «Назад», `Home` — как «Домой».

## Реализованные приложения

1. **Настройки** — подключения, звук, яркость, тема, размер шрифта, обои, сетка, PIN, конфиденциальность и сброс.
2. **Телефон** — набор номера, журнал вызовов, активный звонок, таймер, микрофон, динамик и завершение.
3. **Сообщения** — чаты, отправка текста, изображений и эмодзи.
4. **Камера** — `getUserMedia`, фронтальная/основная камера, фото/видео-режим, ISO и экспозиция.
5. **Галерея** — сетка снимков, полноэкранный просмотр, drag/pinch-подобное масштабирование, удаление.
6. **Часы** — будильники, мировое время, секундомер с кругами и таймер.
7. **Калькулятор** — обычный и научный режимы, история вычислений.
8. **Мои файлы** — виртуальная файловая система, папки, загрузка, редактирование, переименование и удаление.
9. **Samsung Internet** — адресная строка, навигация, 3 стартовые вкладки, iframe и открытие во внешней вкладке.
10. **Samsung Music** — плейлист, синтезированный звук через Web Audio API, прогресс, громкость, повтор и эквалайзер.
11. **Контакты** — поиск, избранное, добавление, редактирование и удаление.
12. **Samsung Notes** — создание, редактирование, удаление, жирный/курсив/списки и предпросмотр.

## Архитектура

```text
src/
├── apps/          # Изолированные модули приложений
├── components/    # Корпус, системные панели и переиспользуемые элементы
├── screens/       # Home, Lock Screen, App Drawer, Recents, Notification Shade
├── state/         # Zustand store и persistence
├── styles/        # Tailwind и глобальная тема One UI
├── test/          # Vitest + React Testing Library
├── utils/         # Метаданные приложений и DOM-снимки Recents
├── App.tsx
├── main.tsx
└── types.ts
```

Все доменные данные и системные настройки находятся в `usePhoneStore`. Приложения не дублируют бизнес-логику и изменяют состояние через типизированные actions. Снимок текущего DOM сериализуется в SVG data URL при открытии панели недавних приложений.

## Ограничения браузерной платформы

- Камере требуется разрешение пользователя и безопасный контекст (`https` или `localhost`).
- Некоторые сайты запрещают загрузку в `iframe` через `X-Frame-Options` или CSP. Для них предусмотрена рабочая кнопка открытия текущего адреса во внешней вкладке.
- Видео записывается через `MediaRecorder` и сохраняется в Галерею в формате WebM. Для защиты `localStorage` действует общий лимит и выводится понятное предупреждение при переполнении.
- Погода работает как локальный динамический источник без API-ключа: температура и состояние обновляются с анимацией. Это предусмотренный требованиями mock-режим с реальной логикой обновления.

## Тесты

```bash
npm test
npm run test:e2e
```

Vitest проверяет компоненты, все приложения и Zustand actions. Playwright покрывает разблокировку, запуск приложения, звонок, сообщение и создание заметки.

## Деплой

Проект является статическим SPA. Каталог сборки — `dist`.

- **Vercel:** Build Command `npm run build`, Output Directory `dist`.
- **Netlify:** Build Command `npm run build`, Publish Directory `dist`.
